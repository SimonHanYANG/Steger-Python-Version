# 颈部测角改进

当前默认入口 `measure_bending()`、`measure_neck()`、`NeckAngleWorker.measure()` 使用相同的几何方向范围法。原始Steger检测、亚像素点、法向、尺度和双极性搜索不变。

## 统一规则

1. 检查有序中心线的两端。末端法向轴与相邻线段的垂线相差超过45°，或末端发生大于90°回折且内侧相邻点法向也不一致时，排除该末端点。法向正负不影响判断。
2. 只向内检查末端，不删除中间点；单端移除弧长不超过20%，总体至少保留75%。超出限制则拒绝测量，避免把真实大弯曲删成直线。原始坐标和法向保留，返回排除索引。
3. 在有效中心线5–95%范围内，用20%总弧长的窗口依次拟合方向。窗口起点间隔不超过1px，窗口内以不超过0.25px间隔等弧长采样，窗口至少3px。
4. 使用float64正交最小二乘，统一沿中心线遍历的方向，以atan2计算并unwrap展开周期。最大方向减最小方向得到弯曲角；直线为0°，不强行折叠大角度。包含中间窗口，S形两端同向也能检出中部弯曲。
5. 同时检查有效覆盖、尺度敏感性、15%/20%/25%窗口敏感性、末端方向和拟合残差。异常末端排除本身就会触发复核标记。有效主轴投影覆盖不足75%时，`angle_deg=None`，局部诊断角度单独保存。

这些阈值是跨样本统一的工程质量规则，不是解剖学真值或已标定的误差界。末端法向和几何不一致也可能来自真实尖锐弯折，应检查被标记的图；一致的平滑回弯会保留。无需按样本编号配置规则。

## 输出与集成

```python
from steger.worker import NeckAngleWorker

def main():
    with NeckAngleWorker(workers=5) as worker:
        result = worker.measure(roi_rgb, neck_mask)
        angle = result['angle_deg']
        status = result['status']
        flags = result.get('quality_flags', [])

if __name__ == '__main__':
    main()  # Windows多进程入口保护；实际软件中初始化一次并持续复用worker
```

传入内存中的原始ROI与mask，读图、分割及显示由软件负责。`review_required`仍需复核，`None`不能当作0°。可视化中绿色为有效中心线，灰色为原始线，红叉为排除点，黄/粉色为最小/最大拟合方向窗口；箭头是方向示意，不是新提取点。

二维TLS使用协方差主轴的解析解，与SVD拟合是同一个最小二乘问题，避免重复调用通用SVD。敏感性检查复用已经验证的有效线段。亚像素加速和五个常驻尺度进程继续保留，不缩减搜索或迭代。

旧方法可显式对照：`measure_end_direction_bending(contour)` 是5–25%/75–95%两端拟合；`measure_cpp_bending(contour)` 是旧项目10点float32原始法向角极差，保留其跨周期假大角度行为。新默认有意不再逐位复现旧C++测角。
