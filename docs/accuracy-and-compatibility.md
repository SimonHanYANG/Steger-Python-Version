# 精度与 HALCON 文档对应记录

参考版本：HALCON Operator Reference 24.11.3.0；核对日期：2026-11-04。

## 核心原则

实现目标是公开算法的功能覆盖和可测量的高精度。HALCON 官方公开文档没有为所有图像给出一个统一的中心线误差、线宽误差或角度误差上限。不能把“输出亚像素坐标”理解成“真实误差必定小于某个小数”。

代码从数学公式独立实现，不复制 HALCON 原生代码，也不依赖第三方 Steger 源码。原论文仅作本地阅读参考，不随仓库重新发布。

## 已落实的官方语义

| 官方说明 | 本项目 |
|---|---|
| 输入单通道图像 | `lines_gauss` 明确拒绝 RGB/多通道；I/O 层另作显式亮度转换 |
| 高斯导数估计局部二次多项式 | `derivatives.py`、`detector.py` |
| 亮线/暗线选择 | 最大绝对特征值及符号判断 |
| 高阈值强种子、低阈值弱连接 | `linking.py` 按连通分量保留至少一个强种子 |
| `ExtractWidth` 控制线宽输出 | `False` 时不做宽度计算或位置偏差校正 |
| `LineModel` 仅在提取线宽时有效 | `none` 不进行不对称偏差校正，也不做额外模型拟合 |
| 三种截面模型 | 条状、抛物线、高斯；解析连续响应和直接数值求逆 |
| 交汇处拆分轮廓 | 输出分支和交汇关系；闭环保留闭合标记 |
| 交汇补全选项 | 可关闭；新增点有 `junction_completed` 标记 |
| 法线指向遍历方向右侧 | `orient_normals`，左右宽度按此方向定义 |

| 暗线 contrast 为负 | 核心求逆及原图拟合均恢复符号 |
| 不改写输入灰度 | 所有运算用副本或派生数组，保留数值尺度 |

## 必须区分的实现差异

1. **卷积截断：**默认 6σ 支持区间，把极小尾部并入端点。使用积分高斯核，导数不进行任意幅度归一化。小 σ 的离散混叠项是理论存在的，测试用独立的 Poisson 求和公式检查，不能通过随意缩放导数来“修正”。
2. **单次 Taylor 与迭代：**默认以较宽的初始邻域启动 Newton 迭代，迭代后重新验证点是否落在对应像素内。否则恰好位于两个像素中间的线可能在两个像素中都被漏掉。`refine=False` 保留论文的单次定位形式。
3. **线宽边缘：**先插值带符号的梯度分量，再求幅值并定位极大值。直接插值已经取绝对值的梯度图会引入中心尖点的插值影响。未声称复刻 HALCON 未公开的边缘搜索实现。
4. **偏差函数：**在标准化尺度 σ=1 上直接数值求逆，替代论文中的有限网格查表。观测不满足模型时明确标记失败。没有把所有线都强行校正成功。
5. **默认精度增强：**在原始像素强度上拟合像素面积积分截面，包含局部方向及常曲率近似。直线的像素面积积分解析计算；曲线采用局部法向和曲率的面积项近似。该步骤是额外扩展，不是 HALCON 已公开的内部步骤。`profile_refinement=False` 可关闭，并保留增强前坐标供比较。
6. **交汇补全：**采用独立的保守端点延伸。仅表示实现了补全功能，不代表与 HALCON 在每个交汇处做出同一决策。对于单个精子颈部测量，建议关闭补全。
7. **边界：**卷积边界默认 `reflect`，另支持 `mirror`、`nearest`。不声称与 HALCON 的所有边界规则一致。真实数据应保留足够周边背景；靠图像边缘的点需要额外检查。
8. **σ 范围：**为避免严重欠采样，本实现拒绝 σ<0.4；这比 HALCON 的形式参数域严格。宽线应按半宽 w 选择足够的 σ，通常参考 σ≥w/√3。过强平滑仍会使相邻结构相互影响。
9. **语言与性能：**使用 Python 调度、NumPy/SciPy 双精度数值计算。没有实现 HALCON 的全部硬件加速策略，速度不作为当前等同性承诺。

## 误差来源与验证边界

无噪声且截面模型完全匹配时，原图模型拟合可接近浮点求解精度。这只能说明受控模型下数值求解正确；实际图像存在光学模糊、光晕、遮挡、截面不匹配和分割偏差，不应将接近零的合成误差推广到真实精子。

默认拟合同时估计背景、幅度、宽度、偏斜、方向和局部曲率。图像很窄、过曝、局部平坦或多个结构重叠时可能不可辨识；代码检查条件数、边界命中和残差，并保留失败状态。宽度不是可以在任意低分辨率图像上无条件恢复的量。

合成噪声标准差以灰度值计量，对比度固定为 150，因此“噪声 3”只表示这组测试中的信噪条件。

## 角度评估

中心线位置精度和方向拟合精度不同。短基线会放大位置误差；只看中心线误差不能保证某个角度误差。基准的圆弧角度真值按实际取段窗口的中点方向差计算，不能把整个圆弧的转角当作两端拟合段的方向差。

后续真实样本验证应固定成像倍率、像素尺寸、灰度处理、mask 对齐、σ、截面模型、取段长度与端点剔除比例。不同尺寸的 ROI 若曾非等比例缩放，必须先恢复物理比例再测角。
