# Steger Python v1.0

This is the first stable release of the current Python Steger implementation.
The project owner reviewed the real-image results, accepted the algorithm's
measurement behavior, and approved this version as the v1.0 baseline.

The release tag is **v1.0**; the Python distribution and runtime version are
**1.0.0**. This release preserves the numerical detection and measurement code.

## Included

- Float64 Gaussian derivative filtering and Hessian-based normal estimation.
- Subpixel line localization, directional linking, width/asymmetry correction,
  and optional additional original-profile fitting.
- Neck self-bending from directed end-window fits, with explicit coverage,
  length, scale, and window sensitivity checks in the batch workflow.
- Recorded algorithm intermediates: derivative maps, eigenvalues, normals,
  candidates, subpixel offsets, and before/after contour coordinates.
- Local HTML/Markdown reports, CSV measurements, PNG visualizations, and NPZ arrays.
- Runtime benchmarks for the full ROI/mask-to-angle worker and its component stages.
- English documentation and a Simplified Chinese README.

## Validation and interpretation

The release is checked with the project's automated test suite and synthetic
accuracy benchmark (84 straight-line cases plus the circular bending example).
The benchmark report records the source hash and individual errors.

Owner acceptance establishes the project's current working baseline. Quantitative
accuracy against annotated real-image centerlines and native HALCON outputs has
not been established. Existing quality flags and insufficient-data outcomes are
retained. The primary bending angle is the difference between fitted end-window
directions; reverse bends can cancel, so inspect the curve and cumulative-turn
diagnostic for S-shaped segments.

For the reviewed real-image batch policy, width/model bias correction and extra
original-profile fitting remain disabled because those profile models have not
been validated for the supplied imaging modality. Other public detector options
remain available as documented.

## Runtime reference

On the development Apple M1, using resident 64x64 RGB ROIs and masks in one
persistent worker thread, the adaptive pipeline averaged **55.4 ms per input**
(**52.1 ms** for successful-angle inputs); the all-input P95 was **83.9 ms**.
This includes conversion, mask processing, Steger extraction, automatic contour
selection, angle calculation, and quality/sensitivity checks. Segmentation,
concurrent segmentation load, file decoding, and visualization are excluded.
These are measurements on the development workload, not cross-platform guarantees.

## Install

Python 3.12 or newer is required. HALCON is not required.

Install the versioned source directly:

```bash
uv pip install "steger-precision[visualization] @ git+https://github.com/SimonHanYANG/Steger-Python-Version.git@v1.0"
```

Alternatively, download the `steger_precision-1.0.0-py3-none-any.whl` release asset:

```bash
uv pip install "steger_precision-1.0.0-py3-none-any.whl[visualization]"
```

Source users can check out the `v1.0` tag and run `uv sync --frozen --extra dev`.
Release assets include a wheel, source distribution, and `SHA256SUMS`.
Local input images and their real-image analysis outputs are not release assets.
