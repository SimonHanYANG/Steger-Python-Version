# Steger Python v1.0.2

当前已确认效果的几何测角与加速版本发布到 **main**，Python包版本为 **1.0.2**。
旧main完整保存在 [archive/main-before-v1.0.2-20261105](https://github.com/SimonHanYANG/Steger-Python-Version/tree/archive/main-before-v1.0.2-20261105)，
提交为 `94235b04db2ebb0714503069dff9eef0416cc3f4`；原有发布标签保持不变。

## 测角变化

- 保留Steger提取的原始点与法向，按统一规则检查异常末端并记录排除索引。
- 在有效中心线5–95%范围内，用20%弧长的小段拟合方向，展开方向周期后取最大值减最小值，直线为0°。
- 沿线中部也参与计算，避免S形弯折在两端同向时相互抵消。
- 覆盖不足75%或拟合段不足3像素时不输出最终角度，局部诊断值单独保存。
- 默认 `measure_bending()`、`measure_neck()`、`NeckAngleWorker.measure()` 使用新口径。
  `measure_end_direction_bending()`、`measure_cpp_bending()`保留此前两种口径，便于历史对照。

## 加速方式

同一张ROI用5种平滑程度同时找线：每个工作进程完成一种平滑程度下的去噪、找点、精细定位和连线。
进程提前建立并复用，读取同一份输入数据；亮/暗线复用计算结果，相邻点成批计算。
可选编译模块执行重复的插值与定位计算，继续使用float64及原有迭代规则；局部直线方向用等价的二维公式求解。

i5-12500、29对64×64输入、1,740次完整调用：**平均5.59 ms，中位数4.96 ms，P95 9.60 ms，最大20.85 ms**。
计时包含内存ROI/mask到完整结果、选线、质量判断及进程通信；不含读图、分割、绘图、启动和排队，未叠加分割负载。
数据对应本机编译模块和5个工作进程，不是通用wheel或每次调用的延迟保证。

## 安装与集成

Python 3.12及以上，不需要HALCON。

```bash
git clone --branch v1.0.2 git@github.com:SimonHanYANG/Steger-Python-Version.git
cd Steger-Python-Version
uv sync --frozen --extra dev --extra native
uv run --frozen --extra native python tools/build_native.py
```

Windows需要MSVC C++构建工具，Linux/macOS需要C编译器。每个平台、Python版本均需构建对应本地模块。
补充平台验证：编译模块通过Windows x64和Linux x64的严格逐位检查；macOS ARM64仍存在浮点末位差异，
因此macOS暂不执行上述构建步骤，使用Python/SciPy后备计算。严格测试标准保持不变。
发行页的通用wheel可以直接安装，但使用Python/SciPy后备计算；测得的5.59 ms配置需按上面步骤从源码构建。

```python
from multiprocessing import freeze_support
from steger.worker import NeckAngleWorker, native_acceleration_available

def main():
    print("本地加速已启用:", native_acceleration_available())
    with NeckAngleWorker(workers=5) as worker:
        # 软件循环中复用worker；ROI和mask由现有线程提供。
        result = worker.measure(roi_rgb, neck_mask)
        angle = result['angle_deg']

if __name__ == '__main__':
    freeze_support()
    main()
```

`angle_deg=None`表示本次没有最终角度，不能作为0°使用。
完整说明见[测角规则](../robust-neck-angle.md)、[构建与集成](../low-latency-worker.md)。
本地真实图像、逐图报告和机器相关二进制保持在本机；源码包含报告与基准生成工具。
