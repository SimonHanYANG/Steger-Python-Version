# Steger Python v1.0.1

A precision-preserving performance update, accepted after review of the
accelerated real-image visualizations. Tag **v1.0.1** and Python package **1.0.1**
are published directly from **perf/angle-worker-v1.0**. This release does not
merge that branch into main; main remains unchanged.

## Changes

- Add `measure_neck(roi, mask)`: aligned resident arrays to neck self-bending
  angle, selection details, quality flags and sensitivity diagnostics.
- Reuse full-ROI derivative fields, Hessian results and cubic interpolation
  coefficients between bright/dark detections at each scale.
- Solve independent Hessian eigenproblems only inside the candidate mask when
  tracing is off. Full-ROI convolution/interpolation and full trace fields remain.
- Reuse the selected contour and identical angle fits instead of recomputing them.
- Retain intermediate derivative, Hessian, normal and subpixel visualizations.

Float64, all scales/rescue rules, both polarities, Newton iteration rules,
linking, selection, angle windows and quality gates retain the accepted behavior.
No new runtime dependency or compiled extension is required.

## Validation

- 109 automated regression tests, including masked/full-field equivalence,
  boundary modes, rescue scales, concurrency and input immutability.
- Exact v1.0 comparisons on 29 real ROI/mask pairs, 210 eligible candidate
  contours and 29 complete intermediate traces. Coordinates, normals, angles,
  selection and quality diagnostics match bit for bit in the tested environment.
- 84 synthetic profiles plus the circular-neck case pass ground-truth gates
  and match the v1.0 full-detector outputs in the optimization validation.
- The release reruns the automated tests and synthetic accuracy suite. The
  [validation manifest](v1.0.1-validation.json) links its source to the accepted
  implementation; version preparation changes only the package version string
  within Python package sources.

The owner accepted the current results. Output equivalence on tested inputs is
distinct from quantitative real-image ground-truth accuracy or native HALCON
equivalence. Existing quality flags and insufficient-segment outcomes remain.

## Runtime

Apple M1; 29 resident 64×64 ROI/mask pairs; one persistent worker. Each run
performs 870 calls per version, with versions interleaved in randomized order.

| Run | v1.0 mean | v1.0.1 implementation mean | Optimized P95 | Mean speedup |
|---|---:|---:|---:|---:|
| Primary | 58.76 ms | 26.52 ms | 49.79 ms | 2.22× |
| Independent repeat | 53.56 ms | 23.64 ms | 38.44 ms | 2.27× |

This includes conversion, mask processing, complete adaptive extraction/search,
angle fitting and quality checks. Disk decoding, visualization, segmentation
and simultaneous segmentation load are excluded. The measurement report retains
the development-source hash and all samples, including occasional long stalls;
this is not a hard real-time latency guarantee. See the
[full performance report](../../reports/performance/README.md).

## Install

Python 3.12 or newer; HALCON is not required.

```bash
uv pip install "steger-precision @ git+https://github.com/SimonHanYANG/Steger-Python-Version.git@v1.0.1"
```

Or install the downloaded `steger_precision-1.0.1-py3-none-any.whl`:

```bash
uv pip install steger_precision-1.0.1-py3-none-any.whl
```

```python
from steger import measure_neck

result = measure_neck(roi, mask)
angle = result["angle_deg"]  # None for missing/incomplete/short segments
```

The array worker requires no matplotlib dependency. Install the `visualization`
extra when generating plots. Release assets include the wheel, source archive
and SHA256SUMS. Private real images and per-image analysis outputs are excluded.
